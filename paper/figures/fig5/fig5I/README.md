# Fig5I

原位 motif 核心打乱实验的四个正贡献合并组：KLF16、SP1、SP2、SP4，以及匹配 Background。主图为 `fig5I.pdf`，使用此前确认的 −2～2（×10⁻³）版本，无显著性星号。2026-11-16 按用户要求去掉全部上下边界三角箭头。画布 8×2.5 英寸；刻度 12 pt、轴标题 14 pt；可编辑 TrueType PDF 文字。

## 目录与重绘

- `plot.py`：离线重绘入口。`code/`：绘图实现和终稿样式。
- `data/plot_values.tsv`：实际绘制的全部 1,453 个点，包含组名、源 DNA 重叠组和原尺度 ΔPC1。
- `data/selected_significance.tsv`：四组原有统计；`data/full_results/`：完整 11 个标签的原始效果表及统计记录。完整表不改变主图只显示四个 motif 的选择。
- `provenance/`：原始 PDF、原始绘图脚本、方法记录及上游实验脚本。保留带边界三角的原始 PDF；当前主图去除了这些标记，改动见 `revision_20261116.json`。
- `audit/`：本地重绘、数据聚合、显示边界、字体及文件完整性核对。
- `package.json`：数据哈希、来源和显示参数。`MANIFEST_SHA256.txt`：包内文件校验清单。

```text
python -m pip install -r requirements.txt
python plot.py --output audit/redraw.pdf
```

离线重绘只读取本包冻结数值，不需 SSH、GPU 或模型，也不重新计算显著性。相对输出路径以本包为根，输出限于包内 PDF。原始上游实验代码仅作溯源，重新运行推理仍需要其记录的模型与原始输入。

## 数据含义

纵轴为原尺度 ΔY_PC1 = WT − disrupted；正值表示打乱后模型预测降低。未使用 log、log1p、标准差归一化或人为偏移。图中乘数 ×10⁻³ 只改变刻度表示。

左半小提琴、中央白色箱线、右侧散点；四组粉色，背景灰色。每点为同一标签内一个阳性 DNA 重叠组的扰动均值，各组点数为 335、223、268、238、389。共享的 pattern / DNA 组可能出现在多个标签中，不能将四个标签视作四份独立的蛋白实验证据。

背景汇总本图四组的匹配对照：先按 match_id 去重，再按源阳性 dna_overlap_group 平均。绘制的是 motif 和背景各自的原始扰动分布；原有检验使用各自一一匹配的背景校正差值，不是用图中混合背景重算检验。

纵轴范围 −0.002～0.002，刻度间隔 0.001。所有数值保留；范围外的 20 个上界点、21 个下界点被坐标范围裁剪，当前图不再添加上下边界三角箭头。未进行散点抽样。按既有口径是 1,453 个跨显示组数据点，并非 1,453 个独立基因。

这四组来自原有探索性 TF/正负贡献合并分析，既有 Holm 校正 P 值不变。原始 44 个 pattern 的主检验均未通过校正显著性。图上不显示星号。
