# 天然 motif 原位打乱：结果与解释

已完成原版五类特征模型 A 的十折、每折五种子推理，实际仅使用 GPU 4、5。GPU 1–3 的逐碱基进程保持运行，进程号 2835604、2835606、2835617 在完成核对时均未改变。

## 覆盖

- 原始归因库：2000 个测试基因；44 个已注释原始 pattern；3698 条 seqlet；11 个 TF 标签。
- 按每个 pattern、每个基因最高 PWM 位点去重后 1620 个单位；其中 1450 个可以通过保持碱基数量的打乱降低 PWM 分数。
- 最终 1368 对 motif/背景，涉及 994 个阳性基因；总体匹配率 94.34%。保留全部 44 个 pattern 和 11 个标签。
- 9 个 pattern 的匹配率低于 90%，在 coverage.tsv 标记，仅作探索性解释。无法打乱或无法匹配的单位没有记作零效应。
- 天然阳性位点来自此前 2000 基因的 seqlet 库；背景来自同折的全量 15351 基因。不能声称已重新归因或扰动全部 15351 个基因的天然位点。

## 指标

motif_delta = 原始预测 Y_PC1 - 原位打乱后预测 Y_PC1。

matched_delta = motif_delta - 相应背景核心的同样打乱效应。

正值表示天然核心相对于匹配背景支持更高的模型暂停相关 PC1；没有额外 log 变换。它是原始尺度 PC1，不是原始 PI 百分比，也不是 NET-seq count 的变化。

## 主要统计结果

主要检验单位为 44 个原始 pattern，按阳性 DNA 重叠组聚类、给予每组相等权重，进行双侧符号置换，并在 pattern 间 Holm 校正。44 个 pattern 均未达到校正后 P<0.05；最小校正 P=0.251675。不能据此断言完全没有序列效应。

按 TF 标签汇总的次要探索性结果中，正贡献 SP/KLF 样 pattern 出现小幅正的匹配效应：

|标签|基因/DNA组数|平均 matched_delta|95% bootstrap CI|次要检验 Holm P|
|---|---:|---:|---|---:|
|SP1|223|0.00026885|[0.00011845, 0.00041746]|0.018600|
|SP2|268|0.00024878|[0.00011065, 0.00038405]|0.018560|
|SP4|238|0.00028282|[0.00013726, 0.00042752]|0.006120|
|KLF16|335|0.00022102|[0.00008813, 0.00035361]|0.030159|

这些标签共享多个原始 pattern，不能解读为分别证实四个蛋白的独立功能。对应负贡献模式没有显著的匹配效应。

CTCF 在原始注释库中只有 Fold03 的 TES 上游负贡献 pattern，本次保留 14 对，匹配效应均值 -0.00024437，95% CI [-0.00058876, 0.00007767]，不显著，匹配率也低于 90%。不能将此结果外推为启动子附近 CTCF 的全基因作用。

## 数值与文件校验

1368 对的原始碱基、方向、PWM 评分、碱基数量和跨窗口共享副本全部核对；共检查 44214 个物理副本碱基映射。50 个模型的无改动单样本/批量预测最大差异 1.78e-6 PC1；平均绝对 motif 扰动效应 4.90e-4，平均绝对背景扰动效应 4.58e-4。

16 张独立 PDF 和 16 页 PDF 图册均为 5×4 英寸、嵌入可编辑字体、无栅格图像，文字未超出画布。数据、匹配计划、排除原因、全部五种子预测和统计表保存在同一服务器目录。见 audit_results.json 和 MANIFEST_SHA256.txt。

这些是固定五类调控特征下的模型条件扰动结果；天然位点由同一模型的贡献模式发现，属于模型内部检验，不能替代独立实验验证。
