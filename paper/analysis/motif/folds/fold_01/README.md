# Fold 01

These resources describe sequence attribution, pattern discovery, motif matching and sequence-based visualization. The archive contains 314 discovered patterns, including 44 with qualifying database matches. TF labels indicate sequence similarity and do not establish a unique bound protein. Tree topology, full-precision matrices and original statistical thresholds are retained.
