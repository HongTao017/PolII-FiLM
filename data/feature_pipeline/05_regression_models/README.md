# 05 regression models

This component builds or organizes gene annotations, sequence composition, biochemical features, target tables and model matrices. Input coordinates are zero-based and half-open after GTF conversion. Missing measurements are retained as missing values until training-fold preprocessing. PI sample columns must not be used as predictors of their own derived PC1 target.

## Usage

See the repository README and `docs/reproduction.md` for environment setup and supported entry points. Archived launch scripts retain their original scope; use a new output directory for new calculations.
